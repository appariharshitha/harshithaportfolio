# Harshitha Appari — Portfolio

Modern React + Vite portfolio for Harshitha Appari.

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files will be created in `dist/`.

## Personal links

Update project GitHub/live-demo links in `src/App.jsx` when your repositories are ready.
